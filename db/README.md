\## Base de datos del proyecto



Esta carpeta contiene la documentación relacionada con la base de datos del proyecto PokeAPI.



\### Datos que se pueden organizar

\- Identificador del Pokémon.

\- Nombre del Pokémon.

\- Tipo de Pokémon.

\- URL de su imagen.



\### Objetivo

Organizar la información de los Pokémon para facilitar su consulta y almacenamiento en el proyecto.





\## Organización de los registros Pokémon



Cada Pokémon podrá representarse mediante un registro con sus datos principales.



\### Campos propuestos

\- id: identificador único del Pokémon.

\- nombre: nombre del Pokémon.

\- tipo: tipo o categoría del Pokémon.

\- imagen: dirección URL de su imagen.



\### Validación de datos

El identificador debe ser único y el nombre no debe quedar vacío.



\### Objetivo

Definir los campos básicos para organizar y consultar los registros Pokémon.
