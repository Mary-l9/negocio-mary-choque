\## Base de datos del proyecto



Esta carpeta contiene la documentación relacionada con la base de datos del proyecto PokeAPI.



\### Datos que se pueden organizar

\- Identificador del Pokémon.

\- Nombre del Pokémon.

\- Tipo de Pokémon.

\- URL de su imagen.



\### Objetivo

Organizar la información de los Pokémon para facilitar su consulta y almacenamiento en el proyecto.
