\## Desarrollo de PokeAPI



Esta carpeta contiene los archivos relacionados con la consulta de información de Pokémon mediante la PokeAPI.



\### Funcionalidades previstas

\- Consultar información de Pokémon.

\- Mostrar nombres e imágenes.

\- Organizar los datos obtenidos de la API.



\### Fuente de datos

Se utilizará la PokeAPI como fuente de información para el proyecto.
