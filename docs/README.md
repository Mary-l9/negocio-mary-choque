\## Endpoints de PokeAPI



Los endpoints permiten solicitar información específica a la API.



\### Consultar un Pokémon

\- Método HTTP: GET

\- Endpoint: https://pokeapi.co/api/v2/pokemon/pikachu

\- Descripción: obtiene información de Pikachu, incluyendo su nombre, habilidades y características.



\### Consultar una especie

\- Método HTTP: GET

\- Endpoint: https://pokeapi.co/api/v2/pokemon-species/25

\- Descripción: obtiene información de la especie de Pokémon con identificador 25.



\### Objetivo

Documentar las rutas principales que se utilizarán para obtener información de Pokémon.





\## Funcionalidades del proyecto



El proyecto permitirá consultar y organizar información de Pokémon mediante PokeAPI.



\### Funcionalidades principales

\- Buscar Pokémon por nombre o identificador.

\- Consultar sus características.

\- Obtener la dirección de su imagen.

\- Mostrar información básica de cada Pokémon.



\### Objetivo

Definir las funcionalidades principales que se implementarán durante el desarrollo del proyecto.





\## Pruebas y verificación



Las pruebas permitirán comprobar que las consultas a PokeAPI devuelvan información correctamente.



\### Casos de prueba

\- Consultar un Pokémon existente, como Pikachu.

\- Verificar que la respuesta incluya su nombre.

\- Comprobar que se obtenga un identificador.

\- Revisar el comportamiento cuando se consulta un Pokémon inexistente.



\### Objetivo

Verificar el funcionamiento de las consultas y detectar posibles errores durante el desarrollo.
