\## Endpoints de PokeAPI



Los endpoints permiten solicitar información específica a la API.



\### Consultar un Pokémon

\- Método HTTP: GET

\- Endpoint: https://pokeapi.co/api/v2/pokemon/pikachu

\- Descripción: obtiene información de Pikachu, incluyendo su nombre, habilidades y características.



\### Consultar una especie

\- Método HTTP: GET

\- Endpoint: https://pokeapi.co/api/v2/pokemon-species/25

\- Descripción: obtiene información de la especie de Pokémon con identificador 25.



\### Objetivo

Documentar las rutas principales que se utilizarán para obtener información de Pokémon.
